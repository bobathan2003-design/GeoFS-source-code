GeoFS Playable Web Demo

This page adds a self-contained playable flight experience that can be hosted as a static website. The archived GeoFS.js file remains in the repository, but the full original simulator needs missing production assets, Cesium setup, and backend services before it can run as-is.

Controls

  • W / S: increase/decrease throttle
  • ↑ / ↓: pitch down/up
  • ← / →: bank left/right
  • Space: level aircraft
  • R: reset flight

To publish this website, push the repository to GitHub and enable GitHub Pages, or drag this folder into Netlify/Cloudflare Pages/Vercel as a static site.
