GeoFS source launcher

Run the archived GeoFS code

This page boots GeoFS.js directly instead of replacing it with a toy simulator. It supplies the browser shell that the archived code expects: Cesium, jQuery, the geofs-ui-3dview element, and a few compatibility shims.

What still has to come from GeoFS/assets?
  • Aircraft definitions from /models/aircraft/load.php.
  • Model, image, skybox, runway, instrument, and sound files.
  • Weather, geocoding, account, and multiplayer backend endpoints.
